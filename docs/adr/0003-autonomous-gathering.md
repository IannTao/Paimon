# 首版采用无人手动操作的跑图采集闭环

2026-10-29，用户确认首版由 Paimon 自动跑图到资源点、调整视角并拾取，执行期间玩家不会手工介入。此决定取代 ADR 0001 中先做手动游玩下的自动拾取、再做跑图采集的顺序，也撤销真实触控与注入点击共存作为首版交付门槛的要求。

首版由程序统一协调移动、视角和拾取输入，优先验证屏幕观察、定位与进度判断、自动操作和结果确认组成的完整闭环。异常由程序在有限范围内恢复，无法恢复则释放输入并结束任务，不将等待玩家移动、转视角或脱困作为正常流程。已有触控共存实验保留为历史证据，不能替代全自动闭环的验证。

同机独立运行、Rust 核心与 Kotlin 平台接入，以及 ADR 0002 的屏幕观察和系统输入边界继续有效。安装和系统授权属于运行准备；执行期间遇到需要人工确认的权限界面时，当前任务应结束，不能声称可自动绕过。首版具体路线、起点条件与恢复上限尚待细化，自动战斗仍属后续范围。
