# 同机独立运行，Rust 核心配合 Kotlin 平台接入

> 2026-10-29 更新：本文的功能推进顺序及手动触控共存要求已被 [ADR 0003](0003-autonomous-gathering.md) 取代；同机独立运行、Rust 核心与 Kotlin 平台接入的决定继续有效。

Paimon 面向与原神运行在同一台实体 Android 手机上的独立使用场景，日常使用不依赖电脑或另一台控制设备。平台接入和资源约束按这一运行形态设计。

用户选择 Rust 实现核心，并允许 Kotlin 接入 Android 平台能力；不要求整个应用完全使用 Rust。具体模块边界和界面技术尚未确定。

功能推进顺序为自动拾取、跑图采集、自动战斗。当前设计访谈首先细化自动拾取，后续阶段的具体范围与架构尚未确认。

用户选择无障碍服务与 Shizuku 作为权限方案。该选择不代表输入路径已经验证：自动拾取必须与玩家手动触控共存，边跑边捡且不打断移动；具体输入实现仍需查证和真机验证。

首版自动拾取仅处理已经显示拾取提示、点击即可获得的物品，不包含对话、开启宝箱、调查或需要攻击的采矿交互。
