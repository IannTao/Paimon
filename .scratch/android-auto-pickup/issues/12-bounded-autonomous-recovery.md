# 12: 采集受阻时自动有限恢复并明确结束

<!-- paimon-github-archive -->
> 2026-10-31 已迁移到 [GitHub #13](https://github.com/IannTao/Paimon/issues/13)。本地编号 12 仅作追溯；以下为迁移前快照，当前状态、依赖及讨论以 GitHub 为准。

**What to build:** 采集任务遭遇暂时看不清、定位不确定、资源未发现或移动无进展时自行有限恢复，恢复成功继续任务，超出上限则释放输入并结束。

**Blocked by:** [09: 从固定起点完成单资源点跑图采集闭环](09-single-resource-gathering.md)；09 的单资源点真机闭环必须有通过证据，仅关闭工单不足以解除阻塞。

**Status:** ready-for-agent

**Lifecycle:** open

**Source:** [Android 全自动跑图采集规格](../../../docs/specs/android-auto-pickup.md)。

同机独立运行，Rust 核心与 Kotlin 平台接入；仅通过屏幕观察与 Android 系统输入操作游戏，不读写游戏内存或修改游戏文件，不预设 Root 或日常外部设备控制。执行期间不依赖玩家游戏操作，遵循 ADR 0003 的全自动采集方向，不依赖旧真实触控共存门槛。测试以完整采集任务入口的外部行为为主，替身与回放不能替代真机游戏证据。

- [ ] 为重新观察、视角调整和重新定位确定并记录具体次数或时限，不无限重试，也不等待玩家脱困。
- [ ] 区分暂态不确定与权限失效、截图会话结束、切离游戏或锁屏；后者直接结束当前任务，不运行中要求补授权。
- [ ] 无法确认位置时不继续盲走，资源缺失或跳过不得计为成功；保留失败原因与恢复次数。
- [ ] 覆盖移动和视角按住期间中断、识别与输入之间状态失效、迟到画面和回执；结束后无新增操作且释放可控输入。
- [ ] 用任务行为回放验证恢复成功与上限耗尽，基准真机验证可复现异常和停止；重新准备后执行视为新任务。
