# 08: 自动调整视角并拾取近处单个物品

<!-- paimon-github-archive -->
> 2026-10-31 已迁移到 [GitHub #9](https://github.com/IannTao/Paimon/issues/9)。本地编号 08 仅作追溯；以下为迁移前快照，当前状态、依赖及讨论以 GitHub 为准。

**What to build:** 基于已导入并通过预检的 BetterGI 基础路线，在程序完成传送及按点移动、确认到达目标后，自动调整视角、识别中文直接拾取提示并取得单个物品，确认结果后交回路线推进。

**Blocked by:** [17: 按导入路线的地面路径点自动跑图](17-bettergi-waypoint-ground-navigation.md)、[18: 自动完成导入路线要求的传送并重新定位](18-bettergi-route-teleport.md)；两项基础能力须有真机通过证据，不能让玩家在任务中补做。

**Status:** ready-for-agent

**Lifecycle:** open

**Source:** [Android 全自动跑图采集规格](../../../docs/specs/android-auto-pickup.md)。

同机独立运行，Rust 核心与 Kotlin 平台接入；仅通过屏幕观察与 Android 系统输入操作游戏，不读写游戏内存或修改游戏文件，不预设 Root 或日常外部设备控制。执行期间不依赖玩家游戏操作，遵循 ADR 0003 的全自动采集方向，不依赖旧真实触控共存门槛。测试以完整采集任务入口的外部行为为主，替身与回放不能替代真机游戏证据。

- [ ] 贯通真实画面、核心识别和决策、视角与点击输入、任务启停和结果显示，不要求玩家运行中对准；目标取自同一份导入路线，不另造脱离路线的拾取点。
- [ ] 视角搜索有明确上限，未知提示不点击；未发现资源或不能确认取得物品时明确失败或未验证，不报告成功。
- [ ] 有实际取得物品的画面证据；命令成功与提示消失均不能单独代替证据。
- [ ] 继承已验证的输入释放及运行条件检查，视角拖动也受停止约束；到达 target 不直接等于取得物品，必须观察实际拾取提示和结果。
- [ ] 用画面序列覆盖明确提示、未知提示、提示消失但未确认取得等场景，并记录真实游戏无人操作结果。
