# 03: 覆盖连续拾取与混合交互场景

<!-- paimon-github-archive -->
> 2026-10-31 已迁移到 [GitHub #4](https://github.com/IannTao/Paimon/issues/4)。本地编号 03 仅作追溯；以下为迁移前快照，当前状态、依赖及讨论以 GitHub 为准。

**What to build:** 玩家边移动边转视角时，应用对首版范围内明确识别的直接拾取物品连续执行拾取；多个提示或物品与其他交互混合出现时，只操作能够确认的拾取目标。

**Blocked by:** [02: 跑通单个物品的自动拾取会话](02-single-item-session.md)。

**Status:** ready-for-agent

**Lifecycle:** open

- [ ] 从单个物品场景扩展到首版范围内的多种中文直接拾取提示，对明确识别的物品全部拾取，不提供黑白名单。
- [ ] 支持连续出现和多个拾取提示的场景；提示消失、移动或顺序变化后，依据当前可确认目标决策，避免继续点击旧目标位置。
- [ ] 对未知、模糊或无法确认的提示跳过；不能为提高拾取率而猜测点击。
- [ ] 在物品与 NPC 对话、宝箱、调查等提示混合出现时，仅点击明确物品提示，不触发非拾取交互，不为采矿执行攻击。
- [ ] 在基准设备上演示连续拾取、持续摇杆和摇杆加视角操作，自动点击不导致停步、触点取消或需要重新落指。
- [ ] 通过完整会话外部行为覆盖正例、混合交互和未知提示，检查实际点击目标和游戏结果，不绑定内部算法或函数调用顺序。
