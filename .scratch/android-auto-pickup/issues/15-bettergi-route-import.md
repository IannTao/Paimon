# 15: 导入并预检 BetterGI 路径点原文件

<!-- paimon-github-archive -->
> 2026-10-31 已迁移到 [GitHub #16](https://github.com/IannTao/Paimon/issues/16)。本地编号 15 仅作追溯；以下为迁移前快照，当前状态、依赖及讨论以 GitHub 为准。

**What to build:** 用户在手机上选择 BetterGI repo/pathing 路线原文件后，看到名称、地图、有序路径点和能力诊断；应用区分格式错误、合法但能力未齐及合法可执行，预检阶段不操作游戏。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Lifecycle:** open

**Source:** [全自动跑图采集规格](../../../docs/specs/android-auto-pickup.md)、[路径点兼容方案](../../../docs/bettergi-pathing-compatibility.md)。

遵循 ADR 0002、0003、0004：同机独立、本地处理、屏幕观察加系统输入，执行期间无人游戏操作。导入、定位和执行的通过证据分别记录，不以旧触控共存门槛阻塞，也不以 07 已通过替代本票能力验证。

- [ ] 固定上游提交和真实样本，贯通文件选择、本地读取、Rust 路线模型与校验、应用预览和错误展示，不要求先录制 Paimon 专用路径。
- [ ] 按已核查 snake_case 和缺省规则读取 info、positions 以及可选 config/扩展字段，支持上游允许的注释与尾随逗号；保留版本、authors/author 等原始信息。
- [ ] 保留浮点坐标精度、数组顺序、可选原始 id、重复位置、点类型、移动模式、动作与参数，不按 id 排序、去重或将游戏坐标解释为屏幕像素。
- [ ] 拒绝缺失/非法/非有限坐标、空点列和不合法结构；未知行为或执行相关配置未支持时仍可预览，但整条路线不可执行，说明点序号、字段与原因。
- [ ] 建立已识别与已能执行分别标记的能力矩阵；07 通过不能把 walk 路线、世界坐标定位或 teleport 标为已支持。原文件导入和预检不发出游戏输入。
- [ ] 通过应用导入入口验证固定提交的 7 点基础琉璃百合样本、含 fly/stop_flying 的 20 点样本、重复点、元数据、注释/尾逗号及错误输入；测试只读预览与拒绝结果，不只断言反序列化成功。
- [ ] 保存来源、提交和原文件身份以供后续任务复用；已导入数据可离线读取，不实现远程仓库订阅、JavaScript 运行时或默认整仓打包。
