# 01: 真机验证自动点击与玩家触控共存

<!-- paimon-github-archive -->
> 2026-10-31 已迁移到 [GitHub #2](https://github.com/IannTao/Paimon/issues/2)。本地编号 01 仅作追溯；以下为迁移前快照，当前状态、依赖及讨论以 GitHub 为准。

**What to build:** 提供可安装的最小验证 APK，让用户在 nubia Z50 Ultra（Android 14、MyOS 14.5.33、中文原神）上，通过真实 Android 输入路径点击指定拾取位置，同时持续操作摇杆或摇杆加视角。验证自动点击是否能在不打断玩家触控的情况下生效，并给出可复现结论。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Lifecycle:** in-progress

- [ ] 最小应用贯通用户触发、Rust 核心与 Kotlin 平台接入到真实系统点击，包含必要的权限准备说明和明确启停；仅进行用户明确启动的测试操作，不实现完整自动识别。
- [ ] 在基准设备上验证持续按住及移动摇杆时的拾取点击，并验证摇杆加视角双指操作期间的拾取点击；重复验证，不以单次点击成功作为结论。
- [ ] 记录设备和系统版本、输入方式、实际游戏显示设置和横屏方向，以及点击是否被游戏接受、是否取得物品。
- [ ] 检查并记录停步、摇杆复位、触点取消、需要重新落指、点击被忽略等现象；通过结论必须有真实游戏结果支撑，模拟接收器不能替代。
- [ ] 权限方案限定为无障碍服务与 Shizuku；不依赖 Root，不读取或修改游戏内存，不修改游戏文件，日常运行不依赖电脑或其他控制设备。
- [ ] 交付验证 APK、复现步骤和明确标记为通过、失败或未验证的结果。无法进行真机测试时标为未验证，不宣称通过。
- [ ] 只有真实触控不中断且点击有效的验证通过，才能解除后续工单阻塞；失败时记录证据并重新讨论输入方案，不以松手再拾取作为降级。
