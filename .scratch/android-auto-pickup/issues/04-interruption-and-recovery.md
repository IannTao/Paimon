# 04: 验证异常中断与用户恢复流程

<!-- paimon-github-archive -->
> 2026-10-31 已迁移到 [GitHub #5](https://github.com/IannTao/Paimon/issues/5)。本地编号 04 仅作追溯；以下为迁移前快照，当前状态、依赖及讨论以 GitHub 为准。

**What to build:** 用户在自动拾取过程中切换应用、失去授权或结束截图会话时，辅助停止点击，并在用户明确恢复后重新依据当前画面工作，不执行中断前遗留的点击。

**Blocked by:** [02: 跑通单个物品的自动拾取会话](02-single-item-session.md)。

**Status:** ready-for-agent

**Lifecycle:** open

- [ ] 完善并验证手动暂停、切换应用、无法确认游戏画面、录屏结束和相关权限撤销时的停止行为；保留单个物品会话已经具备的基本保护。
- [ ] 中断发生在识别与点击之间时，不依据已经失效的会话或旧画面继续发起点击。
- [ ] 权限或画面恢复后不会静默恢复拾取；等待用户明确恢复，必要时重新完成录屏授权。
- [ ] 用户恢复后依据当前有效画面与授权状态操作，不执行暂停或中断前遗留的点击。
- [ ] 从用户可观察的会话行为验证异常、暂停和恢复，包含真实平台生命周期验证；测试替身不能替代所有真机场景。
- [ ] 恢复后的拾取仍不打断玩家触控，不对其他应用或无法确认的画面执行拾取点击。
