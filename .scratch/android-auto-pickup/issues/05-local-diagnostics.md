# 05: 提供用户主动开启的本地诊断

<!-- paimon-github-archive -->
> 2026-10-31 已迁移到 [GitHub #6](https://github.com/IannTao/Paimon/issues/6)。本地编号 05 仅作追溯；以下为迁移前快照，当前状态、依赖及讨论以 GitHub 为准。

**What to build:** 用户遇到拾取识别问题时，可以主动开启诊断并在本地保存必要截图以复现问题；常规使用默认不保存截图，识别和拾取不依赖网络。

**Blocked by:** [02: 跑通单个物品的自动拾取会话](02-single-item-session.md)。

**Status:** ready-for-agent

**Lifecycle:** open

- [ ] 提供用户可操作的诊断开启与关闭入口，能够围绕实际自动拾取会话保存必要截图用于排查。
- [ ] 诊断默认关闭；未主动开启时，日常会话不将游戏截图写入持久存储。
- [ ] 用户关闭诊断后停止新增诊断截图，不将本工单扩展为默认持续录屏或云端收集。
- [ ] 截图保存在本地；画面识别和操作决策不依赖远端服务，在无日常网络连接的条件下验证会话仍可运行。
- [ ] 验证诊断开关对实际截图保存行为的影响，诊断开启或关闭均不改变拾取范围、启停保护和触控连续性要求。
- [ ] 记录实际采用的截图保存及保留方式；本工单不预设未经讨论的云端上传或自动留存期限。
