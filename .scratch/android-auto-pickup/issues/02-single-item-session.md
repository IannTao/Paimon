# 02: 跑通单个物品的自动拾取会话

<!-- paimon-github-archive -->
> 2026-10-31 已迁移到 [GitHub #3](https://github.com/IannTao/Paimon/issues/3)。本地编号 02 仅作追溯；以下为迁移前快照，当前状态、依赖及讨论以 GitHub 为准。

**What to build:** 用户完成权限和画面获取授权后，在游戏中明确开启辅助，应用通过真实画面识别一种明确的拾取提示并自动取得物品；用户可以随时悬浮暂停。将画面获取、Rust 识别与决策、Kotlin 平台接入及真实点击贯通为可演示的完整会话。

**Blocked by:** [01: 真机验证自动点击与玩家触控共存](01-touch-coexistence.md)，且验证结果必须通过；仅关闭该工单不足以解除阻塞。

**Status:** ready-for-agent

**Lifecycle:** in-progress

- [ ] 在基准设备与记录的固定游戏显示设置、横屏方向下，完成一种明确物品提示从画面获取到实际取得物品的闭环；应用运行于原神所在手机。
- [ ] 提供必要的无障碍服务、Shizuku 和画面获取权限引导。采用 MediaProjection 时，每次新建会话由用户手动确认录屏授权。
- [ ] 应用启动默认暂停，仅用户明确开启后才允许拾取；悬浮按钮可随时暂停，暂停后停止发起点击。
- [ ] 权限失效、截图中断或无法确认游戏画面时停止发起点击，等待用户恢复；截图会话结束后由用户重新启动。
- [ ] 未识别或无法确认的提示不点击，不能把未知提示作为默认拾取目标。
- [ ] 真实拾取保持玩家摇杆和双指操作连续，沿用已通过验证的输入路径。
- [ ] 识别和决策完全本地运行，默认不保存截图；首版不提供黑白名单。
- [ ] 以完整自动拾取会话的外部行为验证启停、明确物品拾取、未知提示跳过与基本异常停止；不通过模拟输入测试宣称真实触控已通过。
