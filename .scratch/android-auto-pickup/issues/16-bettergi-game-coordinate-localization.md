# 16: 将手机屏幕定位对应到 BetterGI 游戏坐标

<!-- paimon-github-archive -->
> 2026-10-31 已迁移到 [GitHub #17](https://github.com/IannTao/Paimon/issues/17)。本地编号 16 仅作追溯；以下为迁移前快照，当前状态、依赖及讨论以 GitHub 为准。

**What to build:** 选定导入路线后，应用从真实游戏画面显示与路线一致的当前位置、目标点和定位可信状态；无法定位时明确阻止导航，不靠玩家在运行中标点。

**Blocked by:** [15: 导入并预检 BetterGI 路径点原文件](15-bettergi-route-import.md)、[07: 有画面反馈的自动移动](07-observed-autonomous-movement.md)。

**Status:** ready-for-agent

**Lifecycle:** open

**Source:** [全自动跑图采集规格](../../../docs/specs/android-auto-pickup.md)、[路径点兼容方案](../../../docs/bettergi-pathing-compatibility.md)。

遵循 ADR 0002、0003、0004：同机独立、本地处理、屏幕观察加系统输入，执行期间无人游戏操作。导入、定位和执行的通过证据分别记录，不以旧触控共存门槛阻塞，也不以 07 已通过替代本票能力验证。

- [ ] 优先验证 Teyvat 基础场景，落实地图参照来源、版本、坐标轴/原点/尺度转换和地图匹配方法，明确其他地图或分层位置的支持状态。
- [ ] 贯通真实屏幕、核心定位、路线坐标映射和应用展示；07 局部小地图平移只作为底层证据，不当成绝对游戏坐标，也不直接复制桌面像素缩放常量。
- [ ] 在多个可复现参考位置校验位置和朝向，记录误差、可信阈值、游戏设置与图像数据条件；未经校验的预测位置不能标为已定位。
- [ ] 未知地图、模糊/过期画面、坐标跳变和定位失效时显示原因并阻止盲走；不自动把未知位置当作路线首点。
- [ ] 从导入路线的任务准备入口，以画面回放和真实游戏参考位置验证坐标对应、错误地图及失效停止；不以人工喂已识别坐标代替图像定位验证。
- [ ] 本票交付定位准备和证据，不宣称已实现导航、传送或拾取；预检矩阵仅解锁已真实验证的定位能力。
