# 06: 完成首版真机验收并交付 APK

<!-- paimon-github-archive -->
> 2026-10-31 已迁移到 [GitHub #7](https://github.com/IannTao/Paimon/issues/7)。本地编号 06 仅作追溯；以下为迁移前快照，当前状态、依赖及讨论以 GitHub 为准。

**What to build:** 交付在基准手机上可安装的自用自动拾取 APK 和可复核的验收记录，证明连续拾取、异常恢复、识别准确性和性能满足首版目标，并明确列出未验证项。

**Blocked by:** [03: 覆盖连续拾取与混合交互场景](03-continuous-and-mixed-pickup.md)、[04: 验证异常中断与用户恢复流程](04-interruption-and-recovery.md)、[05: 提供用户主动开启的本地诊断](05-local-diagnostics.md)。

**Status:** ready-for-agent

**Lifecycle:** open

- [ ] 在 nubia Z50 Ultra、Android 14、MyOS 14.5.33、中文原神上验收，记录固定游戏显示设置、横屏方向、应用版本与测试场景。
- [ ] 连续运行至少 30 分钟，覆盖边移动、边转视角及连续拾取；自动点击造成的移动中断、需要重新落指和误点非拾取交互均为 0 次。
- [ ] 人工标注至少 100 次符合首版范围且提示清晰可见的拾取机会，实际成功拾取比例至少 95%；漏识别或因无法确认而跳过也计为未成功拾取。
- [ ] 在成功拾取样本中，至少 95% 从清晰提示出现到触发点击不超过 1 秒，并保留可复核的时序记录。
- [ ] 在固定游戏设置和相同场景下对照开启与关闭辅助的游戏平均帧率，开启后下降不超过 10%；同时记录功耗和温度，不添加未经确认的温度或功耗门槛。
- [ ] 复核默认暂停、悬浮暂停、权限与画面失效停止、用户明确恢复、未知提示跳过及诊断默认关闭的最终用户行为。
- [ ] 交付可安装 APK、权限与启动说明、必要的游戏配置说明和验收结果；日常运行不依赖电脑或其他设备，不承诺公开发布或广泛机型兼容。
- [ ] 未满足指标或测量条件不足时明确记录失败或未验证，不将缺少证据计为通过，不把初始可行性验证等同于最终验收。
